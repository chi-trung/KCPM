### Gap 4: EF Core Migrations Support

**Trước:** `await db.Database.EnsureCreatedAsync()` — no schema versioning

**Sau:** `MigrateAsync()` with `EnsureCreated` fallback:
```csharp
var pendingMigrations = await db.Database.GetPendingMigrationsAsync();
if (pendingMigrations.Any())
    await db.Database.MigrateAsync();  // Proper migrations
else
    await db.Database.EnsureCreatedAsync();  // Backward-compatible fallback
```
