### Vấn đề

### Giải pháp

---

## Script: `jira_log_test_execution.py`

**Chức năng:**
- Sau mỗi CI run, tự động POST comment lên đúng Jira issue
- Comment dạng bảng ADF (Atlassian Document Format) đẹp, có:
  - ✅/❌ Status
  - Bảng: Pass/Fail/Total, Pass rate, Duration, Branch, Commit, Run #
  - Link Allure Report
  - Link GitHub Actions Run
  - Timestamp

**Ví dụ comment trên Jira:**
```
✅ [BACKEND] CI Test Execution – Run #374

| Field        | Value                                    |
|--------------|------------------------------------------|
| Status       | ✅ PASSED                               |
| Tests        | 244 passed / 0 failed / 244 total        |
| Pass rate    | 100%                                     |
| Duration     | 3m 8s                                    |
| Branch       | main                                     |
| Commit       | b83a8c3                                  |
| Run #        | 374                                      |
| Allure Report| https://chi-trung.github.io/KCPM/...     |
| GitHub Run   | https://github.com/chi-trung/KCPM/...    |
```

**Mapping TEST_TYPE → Jira issues:**
| Type | Jira issues |
|------|-------------|
| `backend` | KIEM-4 |
| `postman` | KIEM-21 |
| `e2e` | KIEM-14, KIEM-16 |

## Tích hợp CI Workflows

### `backend-tests.yml`
- Shell: pwsh (Windows runner)
- Parse: `.trx` file XML → `<Counters passed= failed= total=>`
- Post to: KIEM-4

### `frontend-e2e.yml`
- Shell: bash
- Parse: Allure `widgets/summary.json` → statistic
- Post to: KIEM-14, KIEM-16

### `postman-smoke.yml`
- Shell: pwsh
- Parse: Newman JSON output → `run.stats.assertions`
- Post to: KIEM-21
