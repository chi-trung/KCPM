| File | Test ID | Mô tả | Kỹ thuật |
|---|---|---|---|
| `frontend/e2e/citizen_report_test.js` | TC-E2E-002 | Citizen đăng ký → navigate create-report → validation guard | End-to-End + Error Guessing |

| `frontend/e2e/collector_task_test.js` | TC-E2E-004 | Collector login → tasks → state guard (không vào enterprise route) | State Transition Guard |

**Cấu trúc test:**
- Mỗi file có 4–5 Scenario
- Dùng `Feature()` + `Scenario()` của CodeceptJS
- Pattern: login → navigate → assert → negative test
- Timeout: 10–15s cho mỗi bước

**Chạy test:**
```bash
cd Waste-Recycling-Platform/frontend
npx codeceptjs run --steps --grep "TC-E2E"
# Hoặc chạy từng file:
npx codeceptjs run e2e/citizen_report_test.js --steps
npx codeceptjs run e2e/enterprise_assign_test.js --steps
npx codeceptjs run e2e/collector_task_test.js --steps
```
