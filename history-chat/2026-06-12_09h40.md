### 1. Allure Categories — Permission Denied (🔧 IN PROGRESS)

**Root cause xác định:**
- `allure-report-action` (simple-elf) chạy trong Docker container **với user root**
- Files trong `report-main/` được tạo với owner=root → runner user (ubuntu) không thể write
- `chmod -R u+w` chỉ work khi runner là owner, không work với root-owned files

**Fix áp dụng:**
```bash
# Cũ (không đủ):
chmod -R u+w report-main || true

# Mới (fix đúng):
sudo chmod -R 777 report-main 2>/dev/null || chmod -R 777 report-main 2>/dev/null || chmod -R u+w report-main 2>/dev/null || true
```
